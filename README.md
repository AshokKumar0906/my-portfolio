# Ashok Kumar L — Portfolio

Personal portfolio site for Ashok Kumar L, Machine Learning Engineer.

🔗 **Website:** [https://ashok-kumar-l-portfolio.vercel.app](https://ashok-kumar-l-portfolio.vercel.app)

Built with Next.js (App Router), TypeScript, and Tailwind CSS v4, deployed on Vercel.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run start` — serve the production build
- `npm run lint` — run ESLint

## Content

All resume content (profile, skills, experience, projects, education, certifications) lives in `src/lib/data.ts` — update that file to change what's shown on the site.

See [`CLAUDE.md`](./CLAUDE.md) for architecture notes.
